# Switchboard — Frontend

Mobile-first client hosting the dashboard, onboarding, QR pairing UI,
settings, and (via `../overlay`) the floating copilot overlay.

Not yet implemented. Framework choice (React Native vs Flutter) is an
open decision — see `../../docs/ARCHITECTURE.md`.

Planned screens, per `../../BUILD_PROMPT.md`:
- Onboarding (PIN/biometric setup, preferences)
- QR pairing (generate + scan flows)
- Dashboard (connected apps, current run, earnings, mileage/fuel, zone
  quality, savings-module cards)
- Run scoring detail view
- Tag-team session view
- Device & session management
- Settings
