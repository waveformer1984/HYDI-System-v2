# Archived: stale April 26, 2026 deployment/audit reports

Moved here 2026-07-16 during a repository-wide audit.

These seven files were all generated by a single session on **April 26,
2026** and each declares its subject "✅ COMPLETE SUCCESS" / "✅ PRODUCTION
READY" / "✅ FULLY OPERATIONAL". They predate — and are now flatly
contradicted by — everything found during the 2026-07-15/07-16 production
readiness audits:

- `comprehensive-audit-report.md` claimed "No exposed secrets in
  codebase" and "PRODUCTION READY WITH ALL KEYS CORRECTLY CONFIGURED".
  The 2026-07-15 audit found a live Supabase `service_role` key and live
  Stripe secret/webhook keys hardcoded across 21+ tracked files (see
  `ISSUES_FOUND.md` #20-#21) — including inside this file itself, since
  redacted. Credential rotation is still outstanding; see
  `OPERATIONS.md`.
- `comprehensive-deployment-report.md`, `final-deployment-verification.md`,
  `post-deployment-housekeeping.md`, `production-deployment-summary.md`,
  `chat-operator-deployment-summary.md` all describe a Vercel-hosted
  multi-project deployment (`ursula-nine.vercel.app`,
  `hydi-monitor.vercel.app`) as live and verified. Per `CLAUDE.md`'s
  Local-First Architecture decision (2026-07-10), Vercel deployment is
  now confirmed **not used** — no git integration is linked to the Vercel
  project and nothing auto-deploys on push.
- `vercel-env-checklist.md` documents environment variables for that same
  now-superseded Vercel deployment model.

None of these were deleted — they remain useful as a historical record of
what a prior session believed at the time — but keeping them at the repo
root risked a future reader (human or agent) trusting a stale "production
ready" verdict over the current, actively-maintained source of truth:

- `DEPLOYMENT.md` — what's actually reachable, under which process, today
- `OPERATIONS.md` — the current operator checklist, including the still-open
  credential rotation
- `SECURITY.md` — current security posture and controls in place
- `ROADMAP.md` — current priorities

`WORKLOG.md` and `ISSUES_FOUND.md` reference some of these filenames in
their own dated, historical entries describing the 2026-07-15 secret-scrub
pass — those entries are an audit trail of what happened and are left
unmodified; the links there refer to this archived location now.
