How it works: this page fetches each service's URL from your browser every refresh and reads the JSON it returns. Status is derived from online:true, status:"ok"/"healthy", or any HTTP 200.  CORS note: a service shown as unreachable while you know it's up is almost always cross-origin blocking — the browser won't let a page on one origin read another origin's response unless that service sends CORS headers. For localhost:3006 this works best when the page is opened from that origin. Your edits (services + interval) are saved in this browser.
