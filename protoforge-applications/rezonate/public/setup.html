Resonate Setup

Verify the system before making music.

1 · Welcome

Your laptop runs the audio engine — it's the studio. This tablet is the control surface. Heavy work (stem separation, rendering) may take minutes and runs on the laptop, not here.

This wizard checks the installation first. Nothing changes your music until you approve it.

2 · System check

Reads disk, memory, and engine status from the running app — nothing is modified.

3 · Network connection

The laptop and this tablet must be on the same Tailscale tailnet. From the tablet, open:

http://100.118.182.126:3001/setup.htmltailnet address of Frank — Rezonate listens on port 3001

If this page already loaded on the tablet over that address, the link works. Tablet-side connectivity can't be verified from the laptop — it reports BLOCKED until you confirm it on the device.

4 · Co-Pilot check

Exercises suggestions, project context, and a saved-note round trip. One harmless test note is written and read back.

5 · Project check

Pick a project — only real metadata is shown. If nothing exists yet, that's reported, not faked.

6 · Audio test

A real render would re-mix a few bars from your cached stems (e.g. Bad Decision Club, ~80 s on this machine). The source file is never overwritten — output lands in swaps/.

7 · Done
