## DAILY OPERATIONS

### Before Each Session (15 min prep)
- [ ] Equipment powered on and warming up (10–15 min)
- [ ] Gel warmer active and filled
- [ ] Client waiver ready (tablet or printed)
- [ ] Client record reviewed in URSULA: gestational age, session type, any notes
- [ ] Payment confirmed via HYDI (auto-checked at booking; re-verify if flagged)
- [ ] Address confirmed via booking confirmation
- [ ] Supplies checked: gel (min 1 full bottle), wipes, USB drives, printer paper

### During Session
**Informed consent first — always before imaging begins:**
- Client signs waiver (digital via URSULA or paper)
- Waiver content: elective keepsake only (not diagnostic), ALARA protocol, no medical advice
- Digital signatures automatically stored in HYDI client record

**Imaging conduct:**
- Narrate everything — Julia's rapport is the product
- Optimal window: 24–32 weeks; communicate expectation at booking
- Poor image quality (position, engagement): offer reschedule credit at no charge
- Maximum imaging time: 60 minutes per session (ALARA)
- Gender determination: recommend 18+ weeks minimum

**Gallery capture standards:**
- Minimum 20 still images per 3D/4D session
- Minimum 3 video clips (10–15 seconds each)
- Save to client-labeled folder immediately
- Back up to HYDI encrypted cloud before leaving location

### After Each Session
**HYDI CASCADE handles automatically:**
- Gallery delivery email queued (sent at 24 hrs)
- Review request queued (sent at 24 hrs)
- Revenue logged to immutable ledger
- Upsell eligibility checked: early-booking clients flagged for late-pregnancy upgrade offer

**Julia's post-session checklist:**
- [ ] Equipment cleaned and packed
- [ ] Gel wiped from client and transducer
- [ ] Mileage logged in HYDI app
- [ ] Session notes added if anything notable

## EQUIPMENT CARE

- Never transport with probe attached
- Clean probe with approved disinfectant wipe after EVERY session
- Store probe in padded protective case
- Never leave equipment in a hot vehicle (heat damage risk)
- Annual GE maintenance contract: coordinate through Julia's GE rep
- Gel warmer: empty and clean weekly; use only AIUM-compliant gel

## EVENT PROTOCOL

### 72 Hours Before
- [ ] Contract signed + 50% deposit confirmed
- [ ] Venue address and parking confirmed
- [ ] Guest count confirmed
- [ ] Setup time confirmed (arrive 30–45 min early)
- [ ] Gender reveal: if applicable, Julia seals envelope — no spoilers until reveal moment

### Day Of
- Arrive 30–45 min early for setup
- Dedicated table + confirmed power source (bring extension cord)
- Session pacing: ~10–15 min per guest at events
- Social media: host may photograph setup with ClearView branding visible (consented)

### Post-Event
- Gallery delivery within 48 hours (events have more images to process)
- Final balance collected at or before event end
- Event host re-engagement: HEIDI triggers referral request + testimonial ask at 3 days post-event
